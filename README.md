# Examen T1 - Programación Orientada a Objetos

Sistema de gestión de alumnos del Instituto Innova.

## Funcionalidades

- Registro de alumnos.
- Validación de DNI de 8 dígitos.
- Validación de Residencia Temporal de 11 dígitos.
- Clasificación por nivel socioeconómico A, B o C.
- Aplicación de Beca Parcial y Beca Total.
- Cálculo de la pensión final.
- Almacenamiento de alumnos mediante ArrayList.
- Listado de alumnos registrados.
- Control de excepciones para evitar cierres inesperados.

## Clases

- Alumno: contiene los atributos, métodos y validaciones.
- AlumnoControlador: permite agregar y listar alumnos.
- InstitutoInnovaT1: contiene el método main y utiliza Scanner para el ingreso de datos.
